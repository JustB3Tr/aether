# Aether 5.1.0

## Eight pages, one visual identity

An editorial Home portal and featured Originals, a redesigned Games discovery stage, creator/music Apps spotlights, a Focus observatory, a Party rendezvous, three distinct Browser routes, a personal Profile passport and save vault, and grouped Settings with a live motion/spacing preview. Graphite, teal, violet and self-hosted Outfit remain the shared identity.

## Artwork and motion

Focus gains a local observatory backdrop: **95,064 bytes**, approximately 95 KB. The existing mark, favicon and Home portal stay self-hosted. Page/viewer entrances, fine-pointer depth, short hover responses and restrained decorative orbit motion add detail without a new UI framework or runtime package.

Motion preferences distinguish the device setting, explicit full motion and explicit reduced motion. Content remains visible before optional section reveal handling. Phone/tablet layouts keep the real controls readable, and compact Focus layouts bring the primary timer action closer to the top on shorter screens.

## Existing behavior remains

The catalog contains 202 entries, including 16 local Originals, and 27 apps. Browser destinations accept Enter. Launches default to Aether's viewer; the checkbox opens a separate tab through the Aether shell. Heavy proxy engines remain lazy-loaded. Profile backups, supported game saves, favorites, Focus notes/tasks, Party chat and existing volume-based persistence keep their current contracts.

No new runtime packages or database migration are introduced. Keep the existing userdata volume when replacing the Linux AMD64 container. Local image builds and the public-release restart supervisor remain the deployment path.

## Evidence and limits

Current image/deployment identity and checks are recorded by the release owner in [DEPLOYMENT.md](DEPLOYMENT.md). The previous v5.0 audit remains historical evidence. A fresh full app-auditor and app-visionary pass is prepared for the next turn in [NEXT-AUDIT-BRIEF.md](NEXT-AUDIT-BRIEF.md).

This is a visual release, not a new security architecture. Existing public proxy/profile isolation, RH destination TLS validation and dependency findings remain open. Third-party website compatibility and gameplay are not universally guaranteed.
